# 第 01 课复习资料：课程概览与分词

课程版本：Stanford CS336 / Spring 2026。原课日期：2026-03-30。整理日期：2026-10-23。

入口：`main.tex` 是可编辑的完整中文 LaTeX 源文件；`main.pdf` 是由同一源文件编译的阅读版（成功编译后生成）。

当前阅读版共 10 页，首页有可点击的章节目录；已删除标题下的课程年份与原课、整理日期行。

## 主线

给定资源，如何把文本变成模型适合处理的序列？

1. 用全课程地图定位分词的作用。
2. 区分字符串、码点、字节、token ID 与嵌入向量。
3. 从词表大小和序列长度，理解字符、字节、整词方案的取舍。
4. 沿官方例子手算 BPE 训练，再对新文本编码并解码。
5. 认识预分词、特殊 token、实现性能和数据分布的影响。
6. 用一页速查、自测题和参考答案完成复习。

首次阅读按正文顺序；快速复习可先读“一页速查”；检验掌握程度时先独立完成自测题。

## 编辑与编译

源文件采用 `ctexart`，UTF-8 编码与 Fandol 中文字体，无外部图片或本地资料依赖。可用安装了中文支持的 TeX Live / MiKTeX，或支持 XeLaTeX 的在线 LaTeX 编辑器编译；交叉引用和目录需要编译两次。

```powershell
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

当前文件夹仅保留文档，不附带编译器、模型或缓存。PDF 可直接阅读。

## 来源和边界

核心依据为 [第一课官方讲义源码](https://github.com/stanford-cs336/lectures/blob/main/lecture_01.py)，制作时读取的 Git blob SHA 为 `b244cf007a7bff5339114e1dc0c5ced66bd61827`。原始资料请通过文末的官方来源链接访问；本地下载快照已按用户要求清理。

本资料不是录像逐字稿。下一 token 概率、嵌入与计算成本说明、自测题是为复习补充的解释。课程概览仅用于定位，不把后续课程的架构、系统或强化学习细节提前当作本课掌握要求。

BPE 例子沿用讲义玩具实现的频率并列处理顺序，不替代作业手册的实现规范。手算结果已通过从官方讲义抽取的独立定义重新复核：18 字节经三轮合并成为 12 个 token，词表 259 项；新文本 19 字节编码为 16 个 token；另核对了多字节文本、空串往返和非重叠替换。
